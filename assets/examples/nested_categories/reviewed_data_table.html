U.S. Census Bureau, 2024 ACS 1-Year Estimates, Detailed Table B03002 and Data Profile DP03. B03002 percentages use total population; DP03 coverage percentages use the civilian noninstitutionalized population.

The origin display is an additive partition; the coverage display is not. The saved export contains percentages and a derived overlap count, but omits the raw B03002 child counts and DP03 coverage counts. Those raw fields are still needed for an independent audit of all category checks. The derived overlap is not a separately published estimate and has no calculated MOE.

Run completed November 10, 2026 (UTC). Readable cells round numeric values to two decimal places where needed; CSV downloads preserve exported precision. These tables have not completed screen-reader testing.

Stacked Area Chart — ACS data

U.S. Census Bureau, 2021–2024 ACS 1-Year Estimates, Detailed Table B01001. The published male and female estimates form an exclusive and exhaustive partition of each state-year total.

Both figures use a common 0–25 million scale. The total is the top boundary; each category’s count is its band thickness. This is a count display, not a 100% composition chart. Published sex-category count MOEs remain in the table; changes have not been significance-tested.

Run completed November 10, 2026 (UTC). Readable cells round numeric values to two decimal places where needed; CSV downloads preserve exported precision. These tables have not completed screen-reader testing.

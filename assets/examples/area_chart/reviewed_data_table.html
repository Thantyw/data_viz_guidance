Area Chart — ACS data

U.S. Census Bureau, 2021–2024 ACS 1-Year Estimates, Detailed Table B17001, people below poverty threshold (B17001_002E). These are counts within the poverty-status universe, not poverty percentages.

Each panel starts at zero and uses the same vertical scale. The shaded areas do not stack or add across states. Published count MOEs accompany the data; apparent changes have not been significance-tested.

Run completed November 10, 2026 (UTC). Readable cells round numeric values to two decimal places where needed; CSV downloads preserve exported precision. These tables have not completed screen-reader testing.
